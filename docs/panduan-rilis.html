1. PUBLIKASI DOKUMEN WEB (GITHUB PAGES)

Google Play mewajibkan 2 tautan web publik yang aktif sebelum aplikasi dapat disetujui:

  1. Privacy Policy URL: Tautan dokumen kebijakan privasi pengguna.
  2. Data Deletion Request URL: Tautan petunjuk penghapusan akun & data mandiri bagi pengguna.

Langkah Aktivasi di GitHub:

  1. Lakukan git push seluruh kode proyek ke repository GitHub Anda (termasuk folder docs/).
  2. Buka repository Anda di browser → klik tab Settings → pilih menu Pages (di sidebar kiri).
  3. Pada bagian Build and deployment → Source: pilih Deploy from a branch.
  4. Pada bagian Branch: pilih main dan ubah foldernya dari / (root) menjadi /docs → klik Save.
  5. Tunggu 1–2 menit, Anda akan mendapatkan 2 URL publik yang siap dimasukkan ke Play Console:
    • Privacy Policy: https://<username>.github.io/<repository>/privacy-policy.html
    • Data Deletion: https://<username>.github.io/<repository>/delete-account.html

2. BUILD PRODUCTION ANDROID APP BUNDLE (.AAB)

File yang diunggah ke Google Play Console wajib berformat Android App Bundle (.aab) bertanda tangan Keystore resmi (bukan file APK mentah atau expo export).

Perintah Eksekusi Build:

cd frontend
npx eas-cli build --platform android --profile production
Catatan Build EAS:
  • EAS Build akan menggunakan Keystore rilis yang sudah terdaftar di project EAS Anda.
  • Pastikan environment variables (EXPO_PUBLIC_SUPABASE_URL dan EXPO_PUBLIC_SUPABASE_ANON_KEY) sudah terdaftar di EAS Secrets / Environment Variables production.
  • Setelah build selesai, unduh file .aab dari tautan dashboard EAS yang diberikan.

3. PERSIAPAN ASET GRAFIS GOOGLE PLAY STORE

Google Play Console mewajibkan aset gambar untuk tampilan toko (Store Listing):

Jenis Aset Spesifikasi Ukuran Format Ketentuan Google Play
App Icon 512 × 512 piksel PNG 32-bit (Maks 1 MB) Tanpa sudut membulat/transparansi (Google Play otomatis membulatkan sudut).
Feature Graphic 1024 × 500 piksel PNG / JPEG (Maks 15 MB) Banner horizontal promosi; hindari menaruh teks penting terlalu di pinggir.
Screenshots Ponsel Min 2 tangkapan layar (disarankan 4–6) PNG / JPEG (Rasio 16:9 / 18:9) Tangkapan layar nyata fitur aplikasi: Dashboard, Katalog Buku, Peminjaman, Detail Buku.

4. PANDUAN PENGISIAN GOOGLE PLAY CONSOLE

A. App Details & Metadata (Salin dari PLAYSTORE_METADATA.md)

  • App Name: Azelib - Manajemen Perpustakaan
  • Short Description (80 Karakter):
    Kelola koleksi buku, sirkulasi peminjaman, anggota, & laporan perpustakaan mudah.
  • Full Description: Salin teks lengkap dari berkas PLAYSTORE_METADATA.md.

B. Policy & Data Safety Form

  • Privacy Policy URL: Masukkan URL privacy-policy.html hasil GitHub Pages.
  • Iklan (Ads): Pilih "No, my app does not contain ads".
  • Akses Aplikasi (App Access): Pilih "All or some functionality is restricted" → Tambahkan akun demo:
    • Instruksi: "Gunakan akun demo untuk masuk dan mengelola perpustakaan."
    • Username / Email: Email akun admin demo Anda.
    • Password: Password akun demo Anda.
  • Target Audience: Pilih 13 tahun ke atas / Umum (Pendidikan).
  • Data Safety:
    • Data dikumpulkan: Email & Nama (untuk fungsionalitas akun dan identitas).
    • Data dienkripsi saat transit: Ya (HTTPS/TLS).
    • Pengguna dapat meminta penghapusan data: Ya → Masukkan URL delete-account.html.

C. Unggah Bundle (.aab)

  1. Masuk ke menu Testing → Closed testing (atau Internal testing).
  2. Buat Release baru (*Create new release*) → Unggah berkas .aab hasil EAS Build.
  3. Tulis Release Notes (misal: "Rilis awal Azelib v1.0.0") → Simpan dan Tinjau.
