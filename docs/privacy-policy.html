Kebijakan Privasi (Privacy Policy)

Azelib — Terakhir diperbarui: 27 Agustus 2026

Azelib ("Aplikasi") adalah sistem manajemen perpustakaan modern berbasis multi-tenant yang dirancang untuk sekolah, universitas, instansi, dan perpustakaan komunitas. Kami menghargai privasi Anda dan berkomitmen penuh untuk melindungi data pribadi seluruh pengguna dan instansi yang terdaftar.

1. Data yang Kami Kumpulkan

  • Data Akun: Alamat email digunakan sebagai identifikasi unik saat masuk (login). Nama pengguna dan kata sandi dienkripsi secara aman.
  • Data Keanggotaan Perpustakaan: Nama anggota, kategori anggota (Siswa/Guru/Umum), kontak telepon/WhatsApp (opsional), dan alamat (opsional) untuk pencatatan sirkulasi.
  • Data Perpustakaan: Nama perpustakaan, alamat, katalog buku, rak, kategori, dan riwayat peminjaman.
  • Token Akses Pengunjung: Token 6-karakter alfanumerik yang dihasilkan sistem untuk memudahkan pengunjung umum melihat katalog tanpa membuat akun atau login.

2. Izin Perangkat (Permissions)

  • Akses Kamera: Aplikasi Azelib TIDAK meminta atau menggunakan izin kamera (android.permission.CAMERA). Seluruh pencarian dan input data dilakukan secara digital.
  • Akses Jaringan (Internet): Digunakan untuk sinkronisasi data sirkulasi perpustakaan secara real-time ke cloud database terenkripsi (Supabase).
  • Ekspor Laporan PDF: Digunakan secara lokal saat pengelola memilih membagikan berkas PDF laporan via lembar berbagi bawaan Android.

3. Keamanan dan Isolasi Data

Data disimpan pada basis data cloud terenkripsi dengan perlindungan Row Level Security (RLS) yang ketat. Data satu perpustakaan terisolasi secara total dan tidak dapat diakses oleh instansi lain.

4. Penghapusan Akun dan Data

Pengguna memiliki kontrol penuh atas akun dan data mereka. Anda dapat menghapus akun dan seluruh data perpustakaan Anda secara langsung dari dalam aplikasi melalui menu Pengaturan → Hapus Akun & Data, atau mengajukan permintaan penghapusan data melalui halaman web: Permintaan Hapus Akun & Data Azelib.
